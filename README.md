# Calculator-Project--Afame-Technologies


🧮 Standard Calculator 🔢

Developed a basic calculator during my Web Developer Internship at Afame Technologies using HTML, CSS, and JavaScript. This project showcases my ability to design a responsive interface with core functionalities such as addition, subtraction, multiplication, and division, while enhancing my front-end development skills.


Features:

🎨 Responsive Design: The interface adapts seamlessly across all devices, ensuring usability on both mobile and desktop screens.

🛠️ HTML5 & CSS3: Structured with HTML5 and styled with CSS3, offering a clean and modern design.

⚙️ JavaScript Functionality: Implemented key arithmetic functions like addition, subtraction, multiplication, and division.

🚀 Tailwind CSS: Leveraged Tailwind CSS for efficient styling and rapid UI development.


Technologies Used:

HTML5: 📄 For the structure and content.

CSS3: 🎨 For styling and layout.

JavaScript: ⚙️ To handle the core calculator logic and interactions.

Tailwind CSS: 🛠️ For creating a modern, responsive design.
